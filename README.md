# openlaws-website

**Website, teaser and public communication of OpenLaws (`openlaws.org`).**

> *The models will become interchangeable. The knowledge will remain.*  
> *Die Modelle werden austauschbar. Das Wissen bleibt.*

---

## Overview

This repository powers the public presence of **OpenLaws** on GitHub (`openlaws.org`) and complements [openlaws.com](https://openlaws.com).

- **Tone & Positioning**: Intentional teaser — calm, authoritative, non-technical, narrative-driven
- **The Story**: Continuous narrative arc from the EU-funded `openlaws.eu` research pioneer (2014–2016, DG Justice, ODINE & Open Data Institute London) to the AI era (2026+)
- **The Pipeline**: `Sources → Knowledge → Skills → Application`
- **Bilingual**: Full **English (`/` & `/en/`)** and **German (`/de/`)** language switcher
- **Dual Theme**: Native **Light Mode** (`#FFFFFF` / `#F3F4F6`) & **Dark Mode** (`#0F172A` Navy canvas)
- **Brand Identity**: Built strictly with the OpenLaws Design System (`IBM Plex Sans`, `IBM Plex Mono`, Navy `#0F172A`, Knowledge Blue `#0EA5E9`, Application Teal `#14B8A6`)

## Quick Start

```bash
npm install
npm run docs:dev
```

## Build Static Site

```bash
npm run docs:build
npm run docs:preview
```
