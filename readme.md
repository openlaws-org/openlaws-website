# OpenLaws Website

Public website and communication platform of the OpenLaws ecosystem.

## Purpose

The website communicates:

- Vision
- Mission
- Positioning
- Documentation
- Community
- Knowledge Assets
- Updates and Announcements

## Key Messages

OpenLaws is a Legal Knowledge Factory.

OpenLaws makes legal knowledge executable.

The models will become interchangeable. The knowledge will remain.
