# OpenLaws Ecosystem Repositories (`openlaws-org`)

The `openlaws-org` GitHub organization consists of eight coordinated repositories:

| Repository | Layer | Purpose |
| :--- | :--- | :--- |
| [`openlaws-core`](https://github.com/openlaws-org/openlaws-core) | Core Kernel | Canonical ontology, validation, knowledge graph, governance engine, and `/brand` system |
| [`openlaws-spec`](https://github.com/openlaws-org/openlaws-spec) | Standard | Google OKF v0.2 Legal Profile specifications and schemas |
| [`openlaws-connectors`](https://github.com/openlaws-org/openlaws-connectors) | Sources | Ingestion connectors for official legal databases (RIS, EUR-Lex, etc.) |
| [`openlaws-at`](https://github.com/openlaws-org/openlaws-at) | Knowledge | Austrian legal knowledge assets and statutory graphs |
| [`openlaws-de`](https://github.com/openlaws-org/openlaws-de) | Knowledge | German legal knowledge assets and statutory graphs |
| [`openlaws-eu`](https://github.com/openlaws-org/openlaws-eu) | Knowledge | European Union legal knowledge assets (GDPR, EU AI Act, etc.) |
| [`openlaws-website`](https://github.com/openlaws-org/openlaws-website) | Communication | Public documentation and brand platform (`openlaws.org`) |
| [`openlaws-community` / `professional`](https://github.com/openlaws-org) | Application | Reusable skills, workflows, and enterprise integrations |
