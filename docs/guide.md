# OpenLaws Leitfaden

Willkommen bei der Demo von OpenLaws. Dieses Projekt zeigt, wie juristische Texte modern aufbereitet werden können.

## Unser Ziel
Das Rechtssystem sollte für jeden Bürger transparent und leicht zugänglich sein. Aktuelle Portale sind oft unübersichtlich oder für Software-Entwickler schwer anzubinden. 

### Kernfunktionen
* **Volltextsuche:** Blitzschnelles Finden von Paragraphen.
* **Historie:** Vergleiche, wie ein Gesetz vor 5 Jahren aussah.
* **Verknüpfungen:** Automatische Links zwischen sich gegenseitig zitierenden Gesetzen.

> **Hinweis:** Dies ist eine Demoseite, die lokal auf deinem Chromebook läuft. Du kannst diesen Text in VS Code live anpassen!
