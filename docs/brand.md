# OpenLaws Brand & Design System

This page summarizes the canonical **OpenLaws Brand Guide (v0.1.0)** and **Visual Identity (v2.1)**. All source files, SVG logos, and JSON/CSS tokens are stored in `openlaws-core/brand/`.

## Core Colour Tokens

| Token | Hex | Role |
| :--- | :--- | :--- |
| **Navy** | `#0F172A` | Structural foundation, light-mode foreground, dark-mode canvas |
| **Knowledge Blue** | `#0EA5E9` | Knowledge, sources, wordmark "Laws", digital accent |
| **Application Teal** | `#14B8A6` | Practical application, collaboration, transformation |
| **Action Primary** | `#0284C7` | Filled primary buttons with `#FFFFFF` text |
| **Light** | `#F3F4F6` | Dark-mode foreground and inverted structure |
| **White** | `#FFFFFF` | Light-mode canvas |

## Typography

- **Primary Sans**: `IBM Plex Sans` (Weights: 400, 500, 600, 700)
- **Technical Mono**: `IBM Plex Mono` (Weight: 400 — used for YAML, JSON, IDs, ELI/ECLI, SHA-256)
